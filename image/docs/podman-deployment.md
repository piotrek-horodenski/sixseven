# Podman Deployment Guide

This document provides instructions for deploying the Hydra Image application using Podman with the Kubernetes YAML configuration.

## Prerequisites

- Podman (v4.0.0 or later)
- Podman Kubernetes support (podman-kube)
- Persistent volumes configured in your Podman environment

## Understanding the Configuration File

The `config/hydra-image.yaml` file is a Kubernetes-compatible YAML configuration used to deploy the Hydra Image application on Podman.
